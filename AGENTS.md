# Instruções para agentes de IA

Antes de planejar, implementar ou alterar qualquer funcionalidade do Planna:

1. Leia integralmente `README.md` e todos os arquivos de `docs/`.
2. Trate `docs/regras-de-negocio.md` como a fonte oficial das decisões confirmadas.
3. Não transforme itens de `docs/pendencias.md` em decisões silenciosas.
4. Se uma implementação depender de uma regra ausente ou ambígua, registre a dúvida e peça uma decisão antes de assumir um comportamento que altere o produto.
5. Preserve a separação entre bloco planejado, sessão realizada, conteúdo acadêmico e evento acadêmico.
6. Nenhuma geração ou sugestão pode alterar o planejamento confirmado sem ação explícita do aluno.
7. Mantenha a privacidade por usuário: administradores não acessam dados acadêmicos dos alunos.
8. Atualize a documentação quando uma regra de negócio for aprovada ou modificada.

O projeto está em fase de especificação. Não escolha frameworks, banco de dados ou arquitetura definitiva sem que essa etapa seja solicitada.
